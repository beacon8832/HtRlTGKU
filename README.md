# 项目简介

## 核心功能
- 基于 YOLOv8 的衣服实例分割检测系统
- 支持 13 类服装检测：长袖连衣裙、长袖外套、长袖衬衫、短袖连衣裙、短袖外套、短袖衬衫、短裤、半身裙、吊带、吊带裙、裤子、背心、背心连衣裙
- 提供 5000 张标注数据集
- 包含完整源码、训练好的模型及训练结果
- 提供项目运行教程

## 适用场景
- 服装分类与识别研究
- 时尚行业自动化处理
- 零售库存管理系统
- 电商平台商品自动分类
- 服装设计辅助工具

## 技术特点
- 使用 Pycharm/VSCode + Anaconda 开发环境
- 基于 Python 3.9、OpenCV、PyQt5、Ultralytics、Torch1.9 等技术栈
- 提供图形用户界面，支持多种输入方式
- 可自定义置信度和 IOU 阈值
- 支持批量处理和结果保存
